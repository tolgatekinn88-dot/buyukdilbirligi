# Büyük Dil Birliği — Ortak Türk Alfabesi

Ortak Türk Alfabesi projesi için hazırlanmış eğitim amaçlı web sitesi.

## İçerik

- 34 harfli Ortak Türk Alfabesi
- Kazakça ve Kırgızca için eğitim amaçlı dönüştürücü
- Harf ve Ses İlişkisi
- Karşılaştırmalı ses-harf örnekleri
- Projenin amacı ve yaklaşımı

## GitHub Pages

`index.html` ve `logo-mark.png` dosyaları repository'nin kök dizininde bulunmalıdır.
GitHub Pages, `main` dalındaki kök dizinden yayınlanacak şekilde kullanılabilir.
